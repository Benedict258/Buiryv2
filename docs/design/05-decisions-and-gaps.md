## 13. Method and gaps

### How this report was produced

1. **Reading.** I read the files in the brief's order. Facts were then checked against the code with targeted searches: routes, migrations, roles, tokens, components, placeholders and error paths. Code and tests won over the docs (the brief's precedence).
2. **Screenshots.** I ran the development server on mocks (`scripts/dev-server.ts`; MockRelayer, MockTatum, PGlite) and captured 94 screenshots with `scripts/dashboard-shots.ts` into `.buiry-local/design-shots/`, then reviewed a sample by eye.
3. **Contrast and bundle sizes.** Two throwaway scripts outside the repo did the measurements: `contrast.cjs` for WCAG contrast and `bundle.cjs` for bundle sizes after `vite build`. Their output is pasted in sections 6 and 10.
4. **Phase 0 reconciliation and sweeps.** These were done first; they are logged in `Development.md` and `docs/SECURITY_REVIEW.md`.
5. **Commits.** Each file got its own gated commit. The tests stayed at 487 in 53 files throughout. (Now 500 passed, 2 skipped, after Phase 2.)
