## Profiles: switching between testnet and Mainnet

Live runs load an explicit, gitignored profile and never `.env` by accident:

```bash
pnpm tsx scripts/with-env.ts testnet -- <command>     # loads only .env.testnet
```

The runner refuses when `.env.testnet` is missing (there is no fallback to `.env`), when the file names another network in `WALRUS_NETWORK`, `TATUM_NETWORK` or `DEMO_NETWORK`, or when the calling shell already sets a `WALRUS_*`, `TATUM_*` or `DEMO_*` variable (unset them first). It prints variable names, never values. The server and the live demo then refuse to start if WALRUS_NETWORK, TATUM_NETWORK, DEMO_NETWORK, the relayer's `/config` network or a project's declared Sui network disagree. `buiry doctor` prints the networks side by side. Mainnet is a later, deliberate cutover with its own `.env.mainnet`.
