# @buiry/cli

The Buiry command line: connect coding agents to a Buiry server, check setup, and work with project memory.

```sh
npx @buiry/cli --help
npx @buiry/cli login            # sign in to your Buiry server
npx @buiry/cli init             # create or link a project
npx @buiry/cli connect claude-code
npx @buiry/cli doctor           # check configuration, networks and agent setup
```
