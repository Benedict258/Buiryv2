# @buiry/core

The pure core of Buiry: the memory model, namespace derivation, the memory text header, briefing assembly,
redaction and network checks. No I/O.

Buiry is shared, verifiable project memory for AI coding agents. Most people use it through the CLI
(`@buiry/cli`) and the MCP server (`@buiry/mcp-server`); this package is for building on the same rules.
